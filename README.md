# Gold Pilot Cloud

Chmurowy kolektor danych dla Gold Pilota.

- GitHub Actions uruchamia kolektor co około 5 minut.
- Dane rynkowe i ceny dealerów są zapisywane w osobnej gałęzi `data`.
- Portfel użytkownika nie jest wysyłany do chmury i pozostaje lokalnie na iPhonie.
- Kolektor przechowuje historię potrzebną do odtworzenia tego, co działo się podczas zamkniętego Scriptable.

Główne dane: XAU/USD, USD/PLN, COMEX GC, EUR/PLN, CHF/PLN, NBP złoto oraz ceny 10 g u dealerów Tavex, StoneX, Degussa i philoro.
